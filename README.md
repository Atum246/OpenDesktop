## 🔥 What Is This?

OpenDesktop is **NOT** a chatbot. It's a **self-improving intelligence agent** that:

- 🖥️ **Controls your computer** — Mouse, keyboard, windows, files
- 🌐 **Browses the web** — Real search, scraping, deep research
- 💻 **Executes code** — 35+ programming languages, real execution
- 🧠 **Never forgets** — Persistent memory with knowledge graph
- 🧬 **Rewrites its own code** — Self-improvement engine
- 🤖 **Spawns AI armies** — Hundreds of specialized agents
- 🏠 **Controls IoT** — Smart lights, plugs, thermostats
- 🎓 **Trains custom models** — Fine-tune and deploy your own AI
- 📦 **Installs programs** — Any package manager, any platform
- 🎤 **Voice control** — TTS, STT, wake word activation
- 🚀 **Deploys projects** — 18 cloud targets
- 💬 **20 messaging platforms** — Telegram, Discord, WhatsApp, Slack, IRC, Matrix, and MORE
- 🧠 **Knowledge graph brain** — Weighted, auto-relating, decaying memory
- 🔮 **Proactive intelligence** — Thinks before you ask
- 👁️ **Visual understanding** — Sees your screen, clicks by description
- 🛡️ **Trust & safety** — Action preview, rollback, sandbox mode
- 🌐 **API gateway** — REST API, WebSocket, webhooks
- 💻 **Code intelligence** — Review, debug, test generation

## 🚀 Quick Start

### Install

```bash
# Install globally via npm
npm install -g opendesktop-ai

# Run setup wizard
opendesktop --setup

# Start chatting
opendesktop

# Or launch GUI interface
opendesktop --gui

# Short alias
od
```

### One-line install (Linux/macOS)

```bash
curl -fsSL https://raw.githubusercontent.com/Atum246/OpenDesktop/main/install.sh | bash
```

## 🛡️ Security Features

- **AES-256-GCM encryption** for all credentials
- **Command whitelist/blacklist** — block dangerous operations
- **Rate limiting** — prevent abuse
- **Audit logging** — every action logged with context
- **Anomaly detection** — spike detection, unusual hours, rapid-fire
- **Sandbox mode** — test dangerous operations in isolation
- **Auto-lock** — locks after 15 min inactivity
- **Permission tiers** — admin, user, viewer, restricted
- **Trust & Safety** — action preview, rollback system, risk assessment

## 🧠 Memory System

5 types of persistent memory:

1. **📖 Episodic** — Chronological events and interactions
2. **🧠 Semantic** — Facts, knowledge, key-value store
3. **✅ Tasks** — Completed actions and their results
4. **👤 Profile** — User preferences and habits
5. **💬 Conversations** — Saved chat sessions

Plus the **Knowledge Graph Brain** — weighted nodes with auto-relating, decay, and consolidation.
